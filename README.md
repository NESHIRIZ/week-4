# Library Management System

## Overview
This project is a **SQL Relational Database application** designed to manage
library records efficiently. The system stores information about authors,
books, members, and borrowing transactions, making it easier to track
library activities and generate meaningful reports.

## Problem Statement
Many small libraries struggle to manage books, members, and borrowing records
using manual methods. This leads to lost records, poor tracking of borrowed
books, and difficulty generating reports for decision-making.

## Solution
A relational database was designed and implemented using **MySQL**. The database
stores structured data about authors, books, members, and borrowing history.
SQL queries were written to perform **CRUD operations** and generate reports
using table relationships.

## Database Structure
The database consists of the following tables:
- Authors
- Books
- Members
- Borrowings

Primary and foreign keys are used to enforce relationships and maintain
data integrity between the tables.

## Key Features
- Stores and manages authors and book information
- Tracks library members
- Records book borrowing and return dates
- Generates reports using SQL JOIN queries
- Demonstrates full CRUD operations (Create, Read, Update, Delete)
